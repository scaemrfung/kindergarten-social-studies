# Kindergarten Social Studies

Biweekly 30-minute Alberta Kindergarten Social Studies site for SCA (2026–27).

- Live: https://scaemrfung.github.io/kindergarten-social-studies/
- Curriculum: Alberta Social Studies K–6 (2025), Kindergarten
- Structure: 18 lessons · one every two weeks · warm-up / teach / activity / close
- Colour: soft teal + coral on warm cream

## Source

Lesson activities drawn from the EIPS Kindergarten Social Studies toolkits (CC BY-NC-ND 4.0) and the classroom Kindergarten Big Book SMART Notebook files. Outcome wording copied from new LearnAlberta.

## Edit each August

1. Update dates in `school-year.js` to the new EIPS Division Calendar.
2. Keep `CAL.lessons` at 18 for biweekly.
